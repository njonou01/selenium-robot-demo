# Conventions

Ce dossier regroupe les règles pratiques du projet `seleniumdemo`.

## Conventions projet

- `page.md` : écrire une page métier avec les règles du projet
- `workflow.md` : écrire un workflow
- `test.md` : écrire un test
- `scenario.md` : scénariser avec JSON ou Excel
- `params.md` : lire des paramètres avec `MapParams` / `JsonParams`

## Références framework

Les détails techniques du framework ont été déplacés dans :

- `../framework.md`

## Idée générale

On garde ici les conventions d’équipe : ordre d’écriture, nommage, structure des pages,
et place des assertions. Le comportement du framework reste documenté à part.
